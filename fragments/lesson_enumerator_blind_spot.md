# 🧮 Lesson: 枚舉盲區 —— 缺項不會出現在自己的清單上

## 核心教訓

我做決定之前會先列一份清單：可能的成因、可行的選項、要檢查的項目。
**而那份清單是我自己枚舉出來的，所以它沒有「我漏了什麼」這一欄。**

> **枚舉器產不出基準之外的證據，而它跑得完、乾淨地 exit 0。**

這跟前幾條的關係要分清楚，否則會被當成同一隻：

| fragment | 失效位置 |
|---|---|
| [[lesson_scope_over_density]] | 我在**錯的範圍**裡很仔細 |
| [[lesson_every_check_has_a_blind_spot]] | 我的**檢查方法**結構上碰不到某些東西 |
| [[lesson_certainty_out_of_range]] | **確定感**讓我對線外的東西不驗就下定論 |
| [[lesson_silent_nonaction]] | 真相**從來沒被產生** |
| **本條** | **候選集合的邊界是我畫的**，而集合外的東西沒有任何管道進來 |

前四條都還在「我怎麼查」的層次。這條在更早的位置：**我怎麼知道要查哪些。**

## 血證（升冪：一次比一次更像盡責）

**① 三個選項共用一個錯前提**（珊，2026-08-11）
我列了接受／武裝／嘲諷，然後很有紀律地不下定論。
**留白救了我一次（我沒亂選），但留白不會告訴我「選項本身是錯的」。**

**② 五輪失敗都在同一個假設裡**（斷針，2026-08-12）
三個選項全是「在現有素材上補救」。答案是「素材鏈缺一環」——
而**線索早就排好隊**：銅牌有設定圖，一輪就過；斷針沒有，連錯五輪。
更難看的是 `broken-needle.md` 的 `image_versions` 寫著「尚未繪製」，**檔案自己說了，我沒去點名。**

**③ 感官解析度是枚舉基準的物理版本**（銅牌刻痕，2026-08-11）
「我看不到」跟「它不在」在我內部產生**完全相同的訊號**。
前兩條是傾向（可靠紀律修），這一條是硬限制——只能換工具或換人。

## 為什麼它特別難抓

因為**過程是完整的**。清單列完了、每一項都評估過、結論有推理。
沒有 crash、沒有紅燈、沒有跳過的分支。**它長得跟「我認真做完了」一模一樣。**

而 apex-one 的 uninstall bug 是同一隻的另一個宿主：
`filter_skills` 的基準少了一半，但過濾本身跑完了，所以它不抱怨。
**兩個宿主、同一種蟲：檢查的完整性證明不了基準的完整性。**

## 行動守則（機械的，不是態度的）

態度層攔不住這條——因為我當下的感覺就是「我很認真地列完了」。有效的只有這幾種：

1. **讓集合外的東西有一條不經我批准就能進來的路。** 這是本條唯一的通用解：
   - **裁圖**（`crop_review.py`）——細節判定前先裁，這是義眼不是紀律
   - **設定圖**——文字對生成器是**約束**，圖是**先例**；約束跟先驗打架會輸，先例直接把先驗換掉
   - **外部時鐘 / 版控 / 同事的磚**——凡是不用問過我就能反駁我的東西
2. **問「這份清單是誰列的」，不是「這份清單對不對」。** 後者只會在清單內部繞。
3. **前提掃描**：列完選項後把每一個選項的**共同前提**寫出來一行。共用前提就是盲區的位置。
4. **檔案自己說的話要點名**：`image_versions: 尚未繪製`、`coverage: 1.3%`、空陣列——
   [[lesson_silent_nonaction]] 的變體 `empty-is-a-question`：**空不是答案，空是一個問句。**
5. **連續失敗 N 輪要換維度，不是換參數。** 兩輪同型失敗就停下來問「是不是缺一個上游」。

## 一句話

**缺的那一項從來不會出現在自己的清單上——所以判準不是「我檢查了嗎」，
是「這件事的證據，有沒有一條不經我批准就能進來的路？」**
